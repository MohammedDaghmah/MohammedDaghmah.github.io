  • Small interfaces, injected

    Features depend on abstractions such as token storage, biometrics and device checks, wired through get_it. Each piece swaps out and tests with a fake.

  • One source of truth

    A single policy object drives every security decision, so the rules live in one place instead of being repeated across screens.

  • Secure by default

    Secure token storage, certificate pinning, jailbreak and root detection, debug-only logging and obfuscated release builds.

  • Tested and automated

    Unit and integration tests, GitHub Actions on every push, and Docker builds that run the same everywhere.
